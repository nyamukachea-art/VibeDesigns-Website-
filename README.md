Run locally


Download or clone this repository.

Open index.html in a web browser.


No build tools or package installation are required.


Publish with GitHub Pages


Push index.html to the root of a public GitHub repository.

Open the repository's Settings.

Select Pages.

Under Build and deployment, choose Deploy from a branch.

Select the main branch and the / (root) folder, then save.

Wait for GitHub Pages to publish the site. The public address will appear in the Pages settings.


Before launching


Replace the concept portfolio projects with real work, or clearly label them as concept projects.

Update the email address and social media links with the studio's real contact details.

Connect the enquiry form to a form-handling service or backend. The current form is a front-end demo and does not send messages.

Test the website on mobile and desktop.

Add any required privacy and business information before collecting visitor details.
